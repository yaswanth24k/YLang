## Contributing

Contributions are welcome! If you'd like to improve YLang, feel free to:

* Report bugs by opening an Issue.
* Suggest new language features or syntax improvements.
* Improve performance or code quality.
* Enhance documentation and examples.
* Submit Pull Requests with well-tested changes.

Before contributing, please:

1. Fork the repository.
2. Create a feature branch.
3. Commit your changes with clear commit messages.
4. Open a Pull Request describing your changes.

Every contribution—whether it's fixing a bug, improving documentation, or implementing a new feature—is appreciated.
